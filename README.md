# 鮮存股 (Xian Stock)｜個人投資紀錄

繁體中文、手機友善的台股、美股與加拿大股存股紀錄工具。以原生 HTML、CSS 與 JavaScript ES modules 製作，不需要額外套件或建置流程。

## 開啟方式

建議使用本機靜態伺服器開啟網站，讓 ES modules 正常運作。例如在專案資料夾執行：

```powershell
python -m http.server 8000
```

接著開啟 `http://localhost:8000`。網站可部署至 GitHub Pages 等 HTTPS 靜態網站主機。預設使用 Render 報價 API 查詢台股與美股；可在偏好設定切換至 Yahoo Finance。Render 服務需允許網站網域的 CORS 請求。

## 功能

- 記錄買入、賣出、現金配息、股票配股、股票分割與減資。
- 以「股號＋市場」合併持倉，依平均成本更新庫存股數與成本。
- 試算台股、美股與加拿大股手續費；可修改台股牌告費率與折扣、美股／加拿大股每股費用、最低費用及 USD/CAD 對新台幣匯率。
- 輸入台股或美股完整代號會自動帶入 Render 報價 API 的即時價格；報價來源、Render API 網址可在偏好設定修改。Render API 以代號查價，不支援公司名稱搜尋；切換至 Yahoo Finance 可使用公司名稱搜尋及加拿大股報價，但 GitHub Pages 可能因跨來源限制封鎖 Yahoo 請求，建議維持預設 Render API。
- GitHub Pages 建議使用公開儲存庫，網站網址格式為 `https://<GitHub使用者名稱>.github.io/xian-stock/`；需在儲存庫 Settings → Pages 中啟用 `main` 分支的 GitHub Actions 或部署來源。
- 資產摘要以設定的美元與加幣匯率折算，可切換所有總覽金額欄位的主要顯示幣別（TWD／USD）；總市值同時顯示另一幣別等值，並呈現持倉成本、未實現損益、相對前一交易日收盤的日損益及加權報酬率。
- 偏好設定支援中文版（繁體中文）與美語版（English）；語系會儲存在 LocalStorage，並套用至主要頁面、交易表單與設定介面。
- 支援自訂欄位（可於編輯庫存時填寫）、庫存編輯與刪除，以及台股／美股／加拿大股篩選。
- 點選庫存列可開啟持倉詳情，檢視並修改、刪除個別交易紀錄，或新增各類交易；一般交易異動後會重新計算持倉成本與股數。因舊版庫存不同步而標示為「舊版／校正」的明細仍可編輯或刪除，但只更新歷史紀錄，不會重算目前持倉股數與成本。
- 偏好設定可選擇本機或雲端儲存。本機資料保存在目前瀏覽器與裝置；清除瀏覽資料、切換瀏覽器或裝置時不會同步。切換儲存位置會載入該位置的資料，本機與雲端資料分開保留。
- 偏好設定可下載完整 JSON 備份、匯出試算表用 CSV，並從 JSON 還原資料；還原會取代目前瀏覽器資料。
- 雲端模式可連結 Google Drive for desktop、OneDrive、Dropbox 等同步資料夾中的 JSON 檔案。可直接選取既有 JSON；若要建立新檔，按「建立／另存共用檔」並選取資料夾，網站會建立含日期時間的新 JSON，避免覆寫舊檔。檔案成功載入或建立後才可切換至雲端模式，編輯會自動同步；若偵測到外部變更，會暫停自動同步並要求先載入最新版本。網站不是即時多人協作。

## 檔案模組

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 主頁、庫存表格、交易表單、設定表單與對話框 |
| `styles.css` | 桌面與手機版視覺樣式 |
| `js/app.js` | 畫面操作、交易流程、事件處理與資料渲染 |
| `js/storage.js` | 本機與雲端快取讀取、驗證與儲存 |
| `js/calculations.js` | 成本、市值、損益、報酬率與手續費計算 |
| `js/quotes.js` | 台股／美股／加拿大股 Yahoo Finance 搜尋與股價查詢 |
| `js/i18n.js` | 中英文介面文字、市場與貨幣格式 |
| `js/backup.js` | JSON 備份驗證、還原解析與 CSV 匯出 |
| `js/shared-file.js` | 共用檔案權限、瀏覽器端連結保存與外部修改偵測 |

## 計算方式

- 買入成本：買入價格 × 股數 ＋ 手續費。
- 賣出：依賣出前平均持倉成本分攤成本，更新剩餘股數與成本；已實現損益留存於持倉資料。
- 股票配股及分割：增加股數、保留原持倉成本；分割必填比例，股價會依分割比例調整，也可手動設定分割後股價。
- 現金配息：累計配息金額，不變動持倉成本。
- 減資：必填每股退還金額，可選填減少股數；若有減少股數，會分攤成本與已實現損益，並調整股價以維持減資前持倉市值，也可手動設定減資後股價。
- 未實現損益：目前現價 × 持有股數 − 持倉成本。
- 台股手續費預設牌告費率為 0.1425%，實收折扣為牌告費的 28%（2.8 折）；美股預設每股 USD 0.005。券商、交易市場與促銷方案不同，請按實際費用調整。

> 投資摘要僅供個人記錄，不構成投資建議。報價可能延遲或無法取得；實際成交價、手續費、稅額與匯率請以券商資料為準。

## 備份與共用檔案

- JSON 備份包含持倉、交易、自訂欄位、期初庫存與偏好設定；還原前會驗證資料，並要求確認取代目前資料。
- CSV 是供試算表檢視的匯出格式，不提供 CSV 匯入還原。
- 共用檔案功能需要支援 File System Access API 的瀏覽器（例如新版 Chrome／Edge），以及 HTTPS 或 localhost。先選取已同步到電腦的 Google Drive for desktop、OneDrive 或 Dropbox 資料夾，再連結並載入有效 `.json` 檔或建立共用檔；只有檔案讀取驗證成功且已授權時，設定才會開放雲端模式。
- 每位共同使用者都要在自己的瀏覽器連結同一個同步檔案。選用雲端模式後，變更會自動寫入共用檔；也可手動載入最新版本。偵測到外部版本變更時會暫停自動同步，須載入最新版本後繼續；此功能不提供即時共同編輯或跨多筆交易的自動合併。
- 設定中的共用檔案位置會顯示同步資料夾名稱與檔案相對路徑；瀏覽器基於隱私限制不會提供完整絕對磁碟路徑。
