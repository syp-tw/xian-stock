鮮存股 (Xian Stock)｜個人投資紀錄
簡約、無負擔、手機友善的跨國存股記帳工具
專為長期投資人與存股族打造，支援台股、美股與加拿大股。採用純原生 HTML5、CSS 與 JavaScript (ES Modules) 開發，零外部相依套件、無需 npm build 建置流程，即可享有專業看盤軟體般的極速體驗。
🚀 開啟與部署方式
專案採用原生 ES Modules（import / export），請透過本地靜態伺服器啟動，避免直接雙擊 .html 檔案觸發瀏覽器的跨來源安全性限制（CORS）。

2. 靜態託管部署（Netlify / GitHub Pages）
專案支援一鍵部署至 Netlify 或 GitHub Pages。
Netlify 反向代理：專案根目錄附帶 _redirects 檔案，可自動將 /quote-api/* 轉發至 Yahoo Finance 及台灣證券交易所（TWSE/TPEx）開放資料 API，免除跨來源限制（CORS）阻擋。
🌟 核心功能特色
📊 1. 專業級庫存表格與看盤體驗
經典緊湊欄位：第一欄採用台美股看盤常見的**「股票代號+名稱 / 股數」**複合設計，單一欄位兼顧市場標籤（台/US/CA）、股票代號、中文簡稱與持有股數，節省版面且資訊一目瞭然。
全新「股息」欄位：獨立顯示每檔標的已領取的現金配息累計總額。
點擊表頭自由排序：點擊任意欄位表頭（現價、成本、損益、報酬率、市值、股息等）即可切換 ▲ 升冪 / ▼ 降冪，並具備色彩與箭頭指示；排序偏好會自動持久化儲存。
自由調整欄位順序與顯示（⚙ 自訂欄位）：
支援上下移動調整欄位先後順序。
支援核取方塊切換欄位顯示或隱藏。
隨時可一鍵「重設預設順序」。
純淨化日期呈現（去除時間戳記干擾）：全面移除多餘的時分秒時間戳記（Tooltip 及更新標籤），一律採標準 YYYY-MM-DD 純日期格式，視覺乾淨俐落。
主頁預設欄位順序：
股票代號+名稱/股數 ➔ 目前現價 ➔ 平均買入價 ➔ 帳面損益 ➔ 報酬率 ➔ 目前市值 ➔ 投資本金 ➔ 手續費 ➔ 股息 ➔ 操作
(「買入日期」與「獨立股數欄」預設收錄於自訂清單中未勾選，隨時可按需求開啟)
💼 2. 雙幣別資產總覽（Summary Dashboard）
六大核心指標佈局：
總投資本金（目前持倉總成本）
帳面總損益（未實現損益與損益色彩辨識）
累計股息（全持股已領取之現金配息總和，以匯率即時折算）
日損益（對比前一交易日收盤價之即時跳空變動）
加權平均報酬率（支援零成本持有之 +∞% 無限報酬率顯示）
持有標的數（跨市場檔數統計）
一鍵切換 TWD / USD 總覽：內建自訂匯率換算機制，點擊按鈕即可於新台幣與美元總計間無縫切換。
⚡ 3. 0ms 本地極速比對與極致交易輔助
0 毫秒庫存即時聯想：在交易彈窗輸入代號或名稱時，系統於 0 毫秒完成本地持倉快取比對（支援去後綴，如輸入 2330 比對 2330.TW、台積電 比對現存持股），即刻浮現「目前庫存」提示標籤。
賣出一鍵出清：切換為賣出交易時自動預填現存股數；手動部分賣出時，亦保留綠色 現存: X 股（點擊一鍵全賣） 快捷按鈕，避免手動輸入的繁瑣與誤差。
完整交易型態：支援買入、賣出、現金配息、股票配股、股票分割、現金減資／虧損減資。
分割即時預覽：輸入分割比例即時呈現股數前後試算（如 1,000 股 → 2,000 股 (×2)）。
🧮 4. 嚴謹的會計重播引擎與實務稅費精算
台/美/加三國手續費與證交稅：
台股：支援牌告費率、券商折讓與低消設定；賣出時自動依規定計算 0.3% 證交稅（00 開頭之 ETF 自動適用 0.1%）。
台股實務防呆：當交易金額大於 0 時，即使折扣推算為 0 元，系統自動依法規與券商實務按最低 1 元 計收手續費。
美股／加股：支援每股費用與單筆最低費用取大值計算。
出清浮點數消除：當賣出股數達到或超過目前持股（容許 1e-6 浮點誤差）時，強制將持股數與本金歸零，根除 JavaScript 浮點數精度殘留。
資本利得與減資精算：
現金減資退還現金優先沖減成本；退還款項超出本金部分自動計入已實現資本利得。
具備市值折算邊界保護，避免極端數值導致推算股價為負或歸零。
🌐 5. 跨國報價源與雙語系
多報價來源：預設採用自建 Render 報價 API（即時取得台股/美股行情），並支援切換至 Yahoo Finance（支援加股與中文公司名稱搜尋）。
全介面國際化 (i18n)：完整支援繁體中文（zh-TW）與美語（en-US），連同表頭排序提示、貨幣標籤與說明字樣皆能自動切換。
🔒 6. 本機儲存與雲端檔案同步（雙模式）
雙模式獨立保存：支援切換「本機儲存（LocalStorage）」或「雲端共用檔案（File System Access API）」，資料互不干擾。
相容同步資料夾：雲端模式可直接選取 Google Drive for desktop、OneDrive 或 Dropbox 的本機同步資料夾。
SHA-256 指紋防覆蓋：寫入前自動比對檔案雜湊指紋，若偵測到其他裝置變更會主動暫停同步並提醒，防止資料覆蓋。
備份與還原：提供完整的 JSON 格式備份（支援歷程、期初與設定全量還原）及 CSV 試算表匯出。

📖 會計與計算法則參考
項目	計算規則說明
買入成本	買入價格 × 買入股數 ＋ 手續費
平均買入價	持倉成本 (costBasis) / 持有股數 (shares)
賣出分攤成本	依加權移動平均成本按比例扣除：(成本 × 賣出股數) / 持有股數
全數賣出歸零	當賣出股數等於持有股數（容許 1e-6 誤差）時，股數與成本強制設為 0
帳面未實現損益	目前現價 × 持有股數 − 持倉成本
平均報酬率	成本 > 0 時為 (帳面損益 / 持倉成本) × 100%；成本 = 0 且獲利 > 0 時顯示為 +∞%
累計股息	各持倉領取之現金股利加總，總覽依照當下 USD/TWD 匯率換算計入
