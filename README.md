# 鮮存股 (Xian Stock)｜跨國個人投資紀錄

> **簡約、純淨、手機友善的跨國多帳戶存股管理工具**  
> 專為長期存股族、指數化投資者與資產配置人打造。全面支援**台股、美股與加拿大股**，原生採用純 HTML5、CSS 與純 JavaScript (ES Modules) 開發，**零外部相依套件、無需 npm build 編譯**，即可享有如專業券商般的極速看盤與會計記帳體驗。

---

## 🌟 核心特色一覽

### 💼 1. 獨立多帳戶體系與全帳戶加總總覽（Multi-Account Portfolio）
* **單一帳戶／全帳戶自由切換**：
  * **全部帳戶總覽**：一鍵將名下所有帳戶的持倉、成本、市值、累計股息與日損益動態加總，呈現合併報表；表格內自動以**帳戶色彩徽章（Badge）**標記標的歸屬。
  * **獨立帳戶視角**：支援切換至特定帳戶（如「個人核心倉」、「定期定額倉」、「配偶／子女帳戶」），指標與表格即時隔離呈現。
* **投資帳戶管理**：
  * 支援自訂帳戶名稱與隨機色點辨識。
  * **刪除防呆機制**：若帳戶內仍有持倉或交易紀錄，系統將主動阻擋刪除，避免資產誤刪。
* **舊版平滑相容**：舊版備份資料或本機快取匯入時，自動向下相容歸戶至「主要帳戶」，資料無損遷移。

---

### 📑 2. 智慧動態市場分頁（台股／美股／加股自動隱藏）
* **自動過濾未持有市場**：在目前選定之帳戶（或全部帳戶）視角下，即時統計是否有持股。若未持有該市場標的，**對應之市場分頁標籤（台股／美股／加拿大股）自動隱藏**，免除點進空白分頁的干擾。
* **安全回退機制**：若使用者當前停留在特定市場分頁（例如美股），當該市場最後一檔股票出清或被刪除後，系統自動回退至「全部持倉」，防止畫面卡死在已隱藏分頁。

---

### 🛡️ 3. 完整級聯刪除（Cascade Delete）與強提醒機制
* **徹底清除關聯歷史**：在主畫面刪除某帳戶下的持倉標的時，除移除該持倉外，**一併徹底刪除該帳戶該標的之全部歷史交易明細（`transactions`）與期初結餘（`openingBalances`）**，不留任何孤兒數據。
* **雙重安全警示**：刪除前主動彈出確認提示，明確標示「帳戶名稱」、「標的代號」與「即將一併刪除的歷史交易筆數」，杜絕誤觸風險。

---

### 📊 4. 專業級庫存表格與彈性欄位排序
* **複合代號欄位**：第一欄採看盤介面經典的**「股票代號+名稱 / 股數」**設計，單欄整合市場識別（台/US/CA）、股票代碼、中文簡稱與持股數，版面緊湊俐落。
* **全新「股息」獨立欄位**：清晰列出每檔標的歷年累計領取之現金股利。
* **表頭點擊排序**：點選任一欄位表頭（現價、成本、損益、報酬率、市值、股息等）即可於 `▲ 升冪 / ▼ 降冪` 間切換，並自動持久化儲存偏好。
* **自訂欄位順序與顯隱（⚙ 自訂欄位）**：
  * 支援上下拖曳/點擊箭頭調整左右先後順序。
  * 核取方塊可自由隱藏不常用欄位。
  * 提供「重設預設順序」一鍵還原。
* **純淨化日期格式**：全面移除多餘的時間戳記干擾，一律採標準 `YYYY-MM-DD` 純日期格式。

---

### 🧮 5. 嚴謹會計重播引擎與實務稅費精算
* **複合鍵會計帳本**：帳本鍵值採 `${accountId}:${market}:${symbol}` 複合設計，不同帳戶持有相同標的（例如帳戶 A 與帳戶 B 皆買入 2330 台積電）時，交易回放、成本攤提與持股完全獨立。
* **台股證券交易稅精算**：
  * **債券型 ETF（00xxxB 代號結尾）**：依台灣現行稅法依法停徵證券交易稅（**稅率 0%**）。
  * **一般股票型 ETF（00 開頭）**：課徵千分之一（**0.1%**）。
  * **普通股票**：課徵千分之三（**0.3%**）。
* **台股最低手續費實務**：交易金額大於 0 時，即使經券商極低折扣折算後為 0 元，系統依券商與法規實務**強制保底 1 元**計收。
* **出清浮點數消除**：當賣出股數達到或超過目前持股（容許 $10^{-6}$ 浮點誤差）時，強制將成本與股數歸零，根除 JavaScript 浮點數精度殘留。
* **完整交易型態支援**：涵蓋**買入、賣出、現金配息、股票配股、股票分割、現金減資／虧損減資**。

---

### ⚡ 6. 0ms 本地極速股票聯想與防競態報價機制
* **0 毫秒極速快取比對**：輸入股票代號或名稱時，系統於本地即時比對，自動帶入中文簡稱與該帳戶現存庫存。
* **賣出一鍵出清**：切換為賣出交易時自動帶入該帳戶現有持股；亦保留「現存: X 股（點擊一鍵全賣）」快捷按鈕。
* **二階段原子化報價更新**：解決並行請求與狀態競爭問題，非同步抓取行情期間若使用者編輯資料，不會發生舊狀態覆蓋新資料的 Bug。
* **即時 AbortController 清理**：彈窗關閉或快速輸入時，自動中斷過期的網路請求，徹底消除文字閃爍與錯誤覆蓋。

---

### 🔒 7. 本機儲存與雲端檔案同步（雙模式）
* **雙模式獨立保存**：支援切換「本機儲存（LocalStorage）」或「雲端共用檔案（File System Access API）」，資料互不干擾。
* **相容同步資料夾**：雲端模式可直接選取 Google Drive for desktop、OneDrive 或 Dropbox 的本機同步資料夾。
* **SHA-256 指紋防覆蓋**：寫入前自動比對檔案雜湊指紋，若偵測到其他裝置變更會主動暫停同步並提醒，防止多人或多裝置資料覆蓋。
* **全帳戶備份還原**：提供完整的 **JSON 格式備份（支援 v2 多帳戶結構）** 與 **CSV 試算表匯出**。

## 📁 模組化檔案架構

專案實現了高內聚、低耦合的純原生模組設計：

```text
├── index.html                # 語意化 HTML5 主結構、卡片、多帳戶切換器與 Dialog 彈窗
├── styles.css                # 莫蘭迪綠現代 RWD 樣式、帳戶徽章、自訂表格與彈窗排版
├── _redirects                # Netlify 專用轉發規則（免除跨來源 CORS 阻擋）
└── js/
    ├── app.js                # 主入口：多帳戶協調、動態分頁過濾、UI 渲染與級聯刪除
    ├── calculations.js       # 核心財務計算法則（債券 ETF 免稅、手續費保底、加權報酬率）
    ├── ledger.js             # 會計引擎：複合鍵帳本、交易回放、出清歸零與減資精算
    ├── storage.js            # 資料標準化、v2 多帳戶遷移、快取持久化與預設欄位定義
    ├── dialog-transaction.js  # 交易彈窗控制器：帳戶關聯、0ms 聯想與 AbortController 競態防護
    ├── cloud-sync.js         # File System Access API 雲端共用檔案管理器與同步佇列
    ├── shared-file.js        # IndexedDB 檔案 Handle 存取與 SHA-256 指紋檢驗底層
    ├── quotes.js             # Render API 及 Yahoo Finance 行情服務與台股清單查詢
    ├── backup.js             # 支援多帳戶的完整 JSON 備份解析與 CSV 試算表序列化
    └── i18n.js               # 中英雙語系字典對照、動態文字與數值格式化模組
